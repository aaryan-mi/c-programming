# C Programming

A collection of C programming programs, exercises, and practice problems covering core concepts of C language.

## Topics Covered

- **Basics & Operators**: Variables, arithmetic operations, increment/decrement operators, type conversions
- **Conditionals & Control Flow**: `if-else`, ternary conditions, `switch-case`
- **Loops**: `for`, `while`, nested loops, pattern printing, numerical algorithms (Armstrong, reverse number, Fibonacci)
- **Functions & Recursion**: Modular functions, call by value, recursive algorithms (factorial, Fibonacci, sum of natural numbers)
- **Pointers & Memory**: Pointer declaration, address-of (`&`) and dereference (`*`) operators, pointer arithmetic, call by reference
- **Arrays & Multi-dimensional Arrays**: Array traversal, searching, reversing, matrices / 2D arrays
- **Strings**: Character arrays, standard string library functions (`strlen`, `strcpy`, `strcat`, `strcmp`), string manipulation
- **Structures**: Defining structures, array of structures, structure pointers, `typedef`
- **File Handling**: Opening files (`fopen`), modes (`r`, `w`, `a`), reading and writing formatted data (`fscanf`, `fprintf`, `fgetc`, `fputc`), closing files (`fclose`)

## Compilation

Programs can be compiled using GCC:

```bash
gcc filename.c -o filename
./filename
```
